
# 📚 StudyTask — Student Task Manager

A simple, responsive task management website designed to help students organize assignments, track deadlines, and manage their study goals.

## ✨ Features

- ➕ Add tasks with a due date and category
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Filter tasks by all, pending, or completed
- 📊 Track total, completed, and pending tasks
- 💾 Save tasks using browser local storage
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5 — page structure
- CSS3 — styling and responsive layout
- JavaScript — task management and interactivity
- Local Storage — save tasks in the browser
- GitHub — version control and project hosting
- GitHub Pages — website deployment

## 📂 Project Structure

```text
student-task-manager/

```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Add tasks and start organizing your study schedule!
